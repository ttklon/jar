# ZShelper

**ZShelper — локальный голосовой агент-оператор для Windows 10/11.** Слышит, видит экран, имеет руки
(мышь, клавиатура, файлы, приложения, API), сам выбирает модель и инструмент под задачу,
переспрашивает на опасном и умеет работать часами автономно — с полным журналом каждого шага
и алертами в Telegram.

> Бесплатно. Полностью локально. Без аккаунтов и подписок. Собрано на Electron.

## Ключевые идеи продукта

1. **Ансамбль мелких моделей, а не одна большая.** ASR, VAD, wake-word, TTS, OCR, VLM,
   embeddings, reranker, «роутер» 0.6–1.7B, «мозг» 4–8B, «кодер», «критик» — каждая под свою роль.
2. **Автоподстройка под железо.** Профилировщик (статика + калибровка) → tier T0…T3 → набор
   моделей, квантов, контекста, потоков и лимитов. Потолки: ≤60 % RAM, ≤70 % VRAM, пауза в играх.
3. **Оркестратор с реестром способностей.** Планировщик видит 8–15 релевантных инструментов
   (не 60), выбирает скилл-рецепт или строит план; каждый шаг проходит policy gate.
4. **Руки и глаза с проверкой.** UIA-дерево → OCR → VLM (в таком порядке). Координаты кликов —
   только из проверяемых источников. После каждого действия — проверка «что изменилось».
5. **Безопасность по умолчанию.** Классы риска `read / write-local / destructive / external /
   money / identity`, подтверждения с показом diff, корзина вместо удаления, снапшоты, аудит,
   Telegram-кнопки «Стоп/Откатить».
6. **Долгие сессии.** SQLite-очередь, идемпотентные шаги, чекпойнты, восстановление после
   краха, бюджеты и heartbeat — «работай, пока не сделаешь».
7. **Одна кодовая база — любое железо.** T0 (4 ГБ, без GPU) → T3 (32 ГБ, RTX): лестница из 14
   рычагов (модель → квант → контекст/KV → бэкенд → offload → потоки → кэш префикса →
   спекулятивное декодирование → каскад → сжатие промпта → ОС-настройки → планирование).
   Детали и таблицы конфигов — [`research/notes/17-any-hardware.md`](research/notes/17-any-hardware.md).
8. **Кодинг-агент как ядро пользы.** Бриф → исследование с источниками → план → реализация
   в git-worktree → тесты → отчёт → «как продолжить завтра».

## Быстрый старт (исследовательская часть)

```bash
# обновить/дозакачать источники (нужен GitHub token для больших лимитов)
GITHUB_TOKEN=$(gh auth token) python3 tools/collect_sources.py fetch

# найти новое по 30 запросам
GITHUB_TOKEN=$(gh auth token) python3 tools/collect_sources.py discover

# пересобрать индексы
python3 tools/shortlist.py && python3 tools/collect_sources.py index
```

Требования: Python 3.11+, `git`, `gh` (для токена). Никаких зависимостей ставить не нужно —
скрипты на стандартной библиотеке.

## Принципы

- **Local-first.** Базовая функциональность работает без интернета.
- **Least privilege.** Инструмент без объявленных прав не вызывается.
- **Everything is a tool call.** Всё, что меняет мир, проходит через реестр, политику и аудит.
- **Честные границы.** Агент говорит «не могу» вместо «сделал» (и подтверждает результат).
- **Деградация, а не отказ.** На слабом ПК — меньше моделей и возможностей, но работает.

## Дисклеймер

Это ассистент, который **управляет вашим компьютером**. Он намеренно осторожен: спрашивает
подтверждения, пишет аудит, умеет всё останавливать. Не отключайте подтверждения для действий,
которые нельзя отменить, и держите резервную копию важных данных.
