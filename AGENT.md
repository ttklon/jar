# Обязательная точка входа для AI-агентов

Перед любой работой в репозитории прочитай этот файл целиком, затем `AGENTS.md` (обязательно разделы 1–4) и `docs/USER-REQUIREMENTS.md`. Для текущей очереди задач сверяйся также с `docs/ROADMAP.md`. Не начинай изменения кода до этого.

## Правило учёта запросов

В конце каждого запроса пользователя, который меняет требования, приоритеты или решения проекта, добавляй его в `docs/USER-REQUESTS.md` дословно, без исправления орфографии и сокращений. Если сообщение содержит персональные данные, секреты, пароли, токены или иной чувствительный материал — не записывай их; зафиксируй только факт и безопасное резюме. Не записывай служебные сообщения платформы и ответы ассистента как пользовательские запросы.

Перед завершением задачи проверь, что журнал обновлён, файлы находятся в Git, тесты проходят, а в ответе честно описаны изменения и незавершённые пункты. Уведомления, сетевые запросы и скачивание программ/моделей не выполнять скрытно; установка исполняемого кода требует явного согласия и проверяемого источника.

## Ограничение

Этот файл задаёт рабочую инструкцию агенту, но сам по себе не может технически гарантировать, что любой будущий агент или платформа прочитает его либо автоматически запишет каждое сообщение. Агент обязан следовать инструкции в рамках текущей задачи.
