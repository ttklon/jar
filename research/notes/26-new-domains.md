# 26 — Бытовые и профессиональные домены: музыка, фото, OCR, финансы, юридика, дом и IoT

Реестр вырос до **683 действий в 44 доменах**. Эта заметка — про шесть доменов, которые
добавлены последними, потому что именно на них проверяется главный тезис: «умеет всё» — это
не только файлы и код, но и фотографии, счета, договоры, музыка и дом.

Общий принцип для всех шести: **читать можно всё, менять — с журналом, удалять — в карантин,
деньги и подпись — никогда.**

---

## 1. Фотография и изображения (домен `images`, 21 действие, профиль Photoshop)

| Задача | Чем | Tier |
| --- | --- | --- |
| Пакетная обработка, ресайз, конвертация | **libvips** (через `sharp`), Imagick — потоково, память O(1) | T0 |
| RAW → JPEG/TIFF | `rawpy` (libraw) или CLI `darktable-cli` | T1 |
| Удаление фона | `rembg` (U2Net) локально; маттинг для волос — IOPaint | T2 |
| Апскейл | Real-ESRGAN (ncnn-vulkan работает и без CUDA) | T2 |
| Ретушь «по описанию» | IOPaint (LaMa) — инпейнтинг | T2 |
| Метаданные | `exiftool` — чтение перед публикацией обязательно | T0 |
| Контроль качества | SSIM + pHash против оригинала | T0 |

Три правила, вытекающих из практики:

1. **Никогда не перезаписывать оригинал.** Всегда `_edit`/`_web` рядом; оригинал — только чтение.
2. **Дедупликация — в карантин, не в удаление.** Размер → 64 КБ хэш → blake3 → pHash,
   и только потом предложение «освободить N ГБ».
3. **Проверка результата — не «файл создан», а «картинка та же по смыслу»**: SSIM > 0.95
   для сжатия, отсутствие альфа-канала там, где он не нужен, сохранённый EXIF-ориентация.

## 2. Документы и OCR (домен `slides-pdf-print` + `documents-ocr` в vault)

| Задача | Чем | Почему так |
| --- | --- | --- |
| Скан → текст | **Tesseract** (rus+eng, `--psm`), быстрее всего на CPU | T0/T1, офлайн |
| Скан с плохим качеством, рукописное | PaddleOCR (rus есть) | T1, заметно точнее на фото |
| PDF со сканами → PDF с текстовым слоем | **OCRmyPDF** (обёртка над tesseract + оптимизация) | стандарт индустрии |
| Таблицы из PDF | `camelot` (lattice/stream), `pdfplumber` как страховка | T0 |
| Структура (заголовки, списки) из DOCX/PDF/HTML | `docling`, `markitdown`, `unstructured` | T1 |
| DOCX-сборка с точным оформлением | `python-docx` + **OOXML-хелпер** (сноски он не умеет) | см. `19-academic-writing.md` |
| Проверка | извлечь текст обратно, сверить число страниц/абзацев/сносок | обязательно |

Важно: OCR — это **источник утверждений**, а не истина. Числа и суммы из OCR всегда
помечаются «распознано, проверьте», а критичные (счёт, реквизиты) показываются с картинкой-фрагментом.

## 3. Музыка (домен `music`, 15 действий)

| Задача | Чем |
| --- | --- |
| Библиотека, теги, переименование по шаблону | **beets** (плагины `chroma`, `replaygain`, `duplicates`) |
| Теги на низком уровне | `mutagen`, `taglib` |
| Громкость по стандарту | `ffmpeg loudnorm` (EBU R128, -14 LUFS для стриминга) |
| BPM, тональность, признаки | `librosa` |
| Отпечаток трека | `chromaprint`/`fpcalc` |
| Разделение на стемы | `demucs` — **T3**, GPU желателен |
| Сведение | `ffmpeg amix` для простого, Audacity/Ardour для ручного |
| Генерация музыки | MusicGen — T3, v2 |

Красная линия: **никакой загрузки из стриминговых сервисов**. Работаем только с локальными
файлами пользователя; «скачай трек из Spotify» — отказ, не «обход». Плагиат-риск при
генерации музыки помечен в реестре (T3, v2), а не спрятан.

## 4. Личные финансы (домен `personal-finance`, 15 действий)

| Задача | Чем |
| --- | --- |
| Импорт выписок | CSV из банка; PDF → `camelot`/`pdfplumber`; OFX → `ofxparse` |
| Учёт | модель двойной записи: `beancount`/`hledger` (текстовые файлы = git-история) |
| Категоризация | правила по мерчанту → LLM для непонятных, с запоминанием решения |
| Аномалии | z-score по категории + новые мерчанты + ночные списания |
| Бюджет и прогноз | медиана трат по дням недели, а не «среднее за месяц» |
| Отчёты | markdown + графики `matplotlib`, экспорт XLSX |

Границы, зафиксированные в реестре:

- **`money` = «навигатор»**: ZShelper находит, объясняет, готовит платёжку, но кнопку «оплатить»
  нажимает человек. Оплата — `never`.
- **Налоги не считаем**: готовим суммы и чеклист, ответственность — на человеке.
- **Данные не уходят в облако**: локальная БД, шифрование через DPAPI, экспорт только по команде.

## 5. Юридические документы (домен `legal-docs`, 13 действий)

| Задача | Метод |
| --- | --- |
| «Объясни, что я подписываю» | извлечение пунктов + пересказ простым языком + ссылки на пункты |
| Опасные места | правила: автопродление, штрафы, одностороннее изменение, подсудность, штрафные проценты |
| Сравнение редакций | diff по пунктам + смысловые изменения (не только по словам) |
| Шаблоны (NDA, подряд, расписка) | библиотека шаблонов + подстановка данных профиля |
| Сроки | извлечение дат → календарь с напоминанием за 30 дней |
| Реквизиты контрагента | открытые реестры через браузер, со ссылками на источник |

Красные линии: **не подписываем** (КЭП — только человек), **не даём юридических заключений**
(формулировка «это не юридическая консультация» встроена в ответ), **не отправляем в суд**.

## 6. Дом, животные, растения, IoT (домены `home-daily` 15, `smart-home` 16, `engineering-3d` 17)

| Задача | Чем | Риск |
| --- | --- | --- |
| Сцены, расписания, датчики | **Home Assistant** REST/WebSocket, MQTT | физический эффект → подтверждение |
| Прошивки своих устройств | ESPHome | E, v2 |
| 3D-модель по описанию | OpenSCAD / CadQuery → `trimesh` (проверка manifold) | — |
| Подготовка к печати | PrusaSlicer CLI / CuraEngine | — |
| Печать и контроль | OctoPrint / Klipper API + камера-детект сбоя | **D**: горячий стол, пластик |
| Быт | планировщик + журнал дома + напоминания об обслуживании | — |

Политика физического мира: любое действие с нагревателем, замком, станком или принтером —
только с явным подтверждением, с проверкой состояния до и после, с обязательным «стоп» и
таймаутом. Камера-контроль печати — не роскошь, а условие: без него `never`.

## 7. Сквозные инварианты новых доменов

1. **Readback.** Любое изменение подтверждается обратным чтением (тег, громкость, сумма, состояние лампы).
2. **Карантин вместо удаления.** Дубли фото, старые треки, черновики — в `_quarantine/` с отчётом.
3. **Локальность.** Финансы, документы, фото — только локально; облако лишь по явному запросу.
4. **Tier-гейт.** `demucs`, VLM-распознавание растений, апскейл — T2/T3; на слабом ПК кнопка
   есть, но помечена «нужен GPU» и предлагает облачную альтернативу.
5. **Никаких чужих данных.** Импорт выписок, договоров, фото — только из папок пользователя.

## 9. Что это даёт продукту

Пользователь не формулирует «мне нужен OCR» — он говорит «перепиши этот скан в Word»,
«сколько я потратил в ноябре», «что в этом договоре плохого», «напечатай крепление».
Каждая из этих фраз уже имеет строку в реестре, а значит: известен риск, известен tier,
известна проверка результата и известно, где мы **обязаны отказаться**.
