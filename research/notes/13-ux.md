# 13 — Интерфейс: чтобы этим хотелось пользоваться

Требование R-27. Программа сложная внутри; снаружи должна быть **спокойной, быстрой и понятной**
человеку, который не читал документацию.

## 1. Три поверхности — один продукт

| Поверхность | Когда | Что там |
| --- | --- | --- |
| **Главное окно** | настройка, длинные задачи, отчёты | чат, план, журнал, инструменты, настройки |
| **Оверлей (HUD)** | во время работы с приложениями | «слушаю…», шаги, подтверждения, подсветка областей |
| **Трей + горячие клавиши** | 90 % времени | режим, пауза, стоп, быстрые действия |

Плюс «невидимая» поверхность — **Telegram** (алерты и пульт).

## 2. Главное окно: раскладка

```
┌────────────────────────────────────────────────────────────────────┐
│  ⬤ This Helper      [Слушаю ▾]        RAM 34%  GPU 41%  ⚙  ─  ✕    │
├──────────┬───────────────────────────────────┬─────────────────────┤
│ Сегодня  │  Чат / Задача                     │  Контекст           │
│ Задачи   │  ┌───────────────────────────────┐│  • План (шаги)      │
│ Скиллы   │  │ Что нужно сделать?            ││  • Экран (превью)   │
│ Инструм. │  └───────────────────────────────┘│  • Память (факты)   │
│ Журнал   │  [🎙 Говорить]  [⏎ Отправить]     │  • Модель/бюджет    │
│ Настройки│  Лента: сообщения, шаги, диффы    │  • Источники        │
└──────────┴───────────────────────────────────┴─────────────────────┘
```

- **Лента** — не «чат с пузырями», а таймлайн: реплика → план → шаг → результат → отчёт.
  У каждого шага: иконка риска, длительность, кнопка «что именно сделал» (diff/скриншот).
- **Палитра команд** (`Ctrl+K`): «создай папку», «стоп», «покажи журнал», «смени режим» —
  работает и мышью, и голосом (одни и те же действия, одна кодовая база).
- **Никаких модальных диалогов** на пути: подтверждения — карточкой в ленте, не блокирующим окном.

## 3. Оверлей (HUD)

- Небольшая капсула внизу экрана: состояние (слушаю/думаю/говорю), текст распознанного,
  полоса «осталось шагов».
- **Подсветка**: рамка вокруг элемента, который агент собирается нажать («вот сюда»), с
  подписью. Это резко снижает страх «что он сейчас сделает».
- **Кнопка СТОП** всегда на месте и всегда доступна (в т.ч. `Ctrl+Alt+Esc`).
- Перетаскивается, скрывается, «залипает» на выбранном мониторе.
- Прозрачность/клики: `setIgnoreMouseEvents(true)` в режиме «не мешать», кроме кнопок.

## 4. Подтверждения, которые не бесят

| Ситуация | Решение |
| --- | --- |
| Много однотипных шагов | «Разрешить все 5 шагов этого типа» (одна кнопка) |
| Опасное действие | Показать **diff** (что удаляется/меняется), а не абстрактное «продолжить?» |
| Пользователь занят | Не блокируем: карточка ждёт, TTL 5–10 мин, напоминание |
| Ответ голосом | Короткие «да/нет», распознаём, но переспрашиваем при неуверенности |
| «Разрешить всегда» | Только для `write-local`, с показом области действия и датой отзыва |

## 5. Состояния и обратная связь

Обязательные состояния: `idle`, `listening`, `thinking`, `acting`, `waiting-user`,
`paused`, `error`, `offline`. Для каждого — свой цвет/иконка и **одна фраза** что происходит.
Никаких «крутилок» без текста: пользователь должен понимать, ждёт ли он 2 секунды или 2 минуты
(показываем «примерно 40 с, этап 2/5»).

Ошибки — человеческим языком:
- ❌ «Error: ENOENT spawn llama-server EACCES»
- ✅ «Не смог запустить движок моделей: антивирус заблокировал файл. Открыть инструкцию?»

## 6. Дизайн-система

- Тёмная тема по умолчанию (агент работает рядом с редакторами/играми), светлая — есть.
- Палитра: нейтральный фон (#0E1116), акцент — спокойный синий/бирюза, риск — янтарный,
  опасность — красный **только** для destructive.
- Типографика: Inter (UI) + JetBrains Mono (код/логи); масштаб 1.0–1.25.
- Компоненты: Radix + Tailwind + свой слой «агентских» (`StepCard`, `RiskBadge`, `PlanView`,
  `ToolCard`, `MemoryChip`, `Waveform`).
- Движение: 120–200 мс, `prefers-reduced-motion` уважаем.
- Иконки: Lucide (единый набор).
- Доступность: контраст AA, полная навигация с клавиатуры, `aria-live` для озвучки состояний,
  совместимость с экранными дикторами (это ещё и тест нашего же UIA-слоя).

## 7. Первый запуск (критично для доверия)

5 шагов, ≤ 3 минут:
1. «Привет. Я работаю у вас на компьютере и никуда не отправляю данные» + уровень железа.
2. Выбор режима: `PTT` / `wake word` / `только текст`.
3. Подбор моделей под железо (прогресс: «качаю 1.4 ГБ, это займёт ~4 мин») + кнопка
   «выбрать вручную».
4. Разрешения: микрофон, рабочий стол, папки (по одной, с объяснением зачем).
5. Демо: «Скажите: Хелпер, создай папку Демо на рабочем столе» → успех → «Вот и всё».

Никаких регистраций, ключей, «войдите в аккаунт» на этом пути.

## 8. Настройки: только нужное наверх

| Раздел | Содержимое |
| --- | --- |
| Голос | устройство, PTT, wake word, скорость, голос TTS |
| Модели | текущий tier, занято RAM/VRAM, кнопки «пересчитать профиль», «освободить память» |
| Разрешения | режим (paranoid/balanced/trusted), правила, «что можно» матрицей |
| Инструменты | MCP-серверы, коннекторы, скиллы, «здоровье» каждого |
| Память | что помню, «покажи всё», «забудь», TTL |
| Оповещения | Telegram-привязка, что присылать, тихие часы |
| Журнал | поиск по действиям, экспорт |
| Дополнительно | автозапуск, горячие клавиши, обновления, папки |

Каждый переключатель — с одной строкой «что изменится». Экспорт/импорт настроек в JSON.

## 9. Микро-детали, которые создают ощущение «сделано с любовью»

- Голосовой ответ **начинается** с подтверждения: «Делаю» (а не молчание на 2 секунды).
- «Отменить» доступно 5 секунд после действия (toast с таймером) — для обратимого.
- При простое — «подсказка возможностей» («умею: пересказать видео, поставить встречу…»).
- Показывает **свои ограничения**: «это приложение защищено от автоматизации, покажу шаги».
- Копирование отчёта одной кнопкой в markdown.
- Никогда не двигает окна и не забирает фокус без нужды (уважение к «я работаю»).
- Индикатор записи невозможно случайно скрыть, но можно свернуть в точку.

## 11. Открытые вопросы

- Один экран «лента» или два режима (чат / рабочий стол задач)? Гипотеза: лента с фильтрами.
- Оверлей на втором мониторе при работе с видео — где показывать шаги? Нужен «прилипающий
  к активному окну» режим.
- Нужна ли «тёмная тема для скриншотов, отправляемых в Telegram» — маскировать приватное?
