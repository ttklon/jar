# 00 — Видение и границы продукта

## Одна фраза

**This Helper — локальный, бесплатный, автономный голосовой агент-оператор для Windows 10/11,
который слышит, видит экран, имеет руки (мышь/клавиатура/файлы/приложения/API), сам решает,
какой моделью и каким инструментом действовать, спрашивает подтверждение на опасном и умеет
работать часами без присмотра — с полным аудитом каждого шага.**

## Что это НЕ такое

| Не это | Почему важно |
| --- | --- |
| Не чат-бот с плагинами | Чат — лишь одна из поверхностей (есть голос, оверлей, палитра, трей) |
| Не облачный ассистент | Всё локально; сеть — только по явному действию инструмента |
| Не «обёртка над Ollama» | Свой роутер моделей, свой бюджет памяти, свои воркеры |
| Не хакерский автопилот | Каждое опасное действие — через политику и подтверждение |
| Не «одна большая модель» | Ансамбль мелких специализированных моделей под железо |

## Требования пользователя → декомпозиция

Оригинальная формулировка (голосом) разложена на проверяемые требования. `R-xx` — идентификатор
для трассировки в коде/тестах.

### Голос и слух
- **R-01** Полностью голосовое управление: «сказал — сделал». Push-to-talk (по умолчанию) и
  режим wake-word («Эй, Хелпер»).
- **R-02** Режим «слушай 24/7» — включается явно, индикатор записи всегда виден, кнопка стоп
  в один клик и по горячей клавише.
- **R-03** Понимает русский (основной) + английский; смешанная речь («сделай commit и push»).
- **R-04** Перебивание (barge-in): пока говорит — можно перебить голосом.

### Действия и руки
- **R-05** Файлы: создать/переместить/удалить/переименовать/найти; «папка в правом верхнем углу
  рабочего стола» — то есть работа с реальными координатами иконок, а не только с путями.
- **R-06** Приложения: запуск, фокус, меню, горячие клавиши, drag&drop, ввод текста, скролл.
- **R-07** Браузер: открыть, найти, прочитать страницу, заполнить формы, скачать.
- **R-08** Медиа: YouTube-поиск, воспроизведение, пауза; скачивание аудио/видео; транскрипт.
- **R-09** Видеомонтаж «вместе со мной»: пошаговый режим в CapCut/Premiere/DaVinci — агент
  диктует шаг, ждёт подтверждения, проверяет результат по экрану.
- **R-10** Длинное видео → краткий пересказ с таймкодами и «что тут полезно для меня».
- **R-11** Заметки/календарь/почта/Telegram — через коннекторы (R-21).

### Мозги и оркестрация
- **R-12** Много мелких моделей, каждая под свою задачу (ASR, TTS, VAD, embed, rerank, OCR,
  VLM, планировщик, кодер, критик, безопасность).
- **R-13** Автопрофилирование ПК при первом запуске и при изменении железа; все модели, веса,
  кванты и лимиты подбираются под него.
- **R-14** Не забивать ресурсы: целевой потолок (по умолчанию ≤ 60 % RAM, ≤ 70 % VRAM,
  ≤ 50 % CPU в фоне), пауза при играх/полноэкранном видео/батарее.
- **R-15** Оркестратор сам определяет, какие агенты/скиллы/инструменты/MCP-серверы нужны.
- **R-16** Планирование: план → шаги → проверка → отчёт; план виден и редактируем до старта.

### Кодинг (одна из главных задач)
- **R-17** Полный цикл: сбор требований → исследование в интернете → детальный отчёт с
  источниками → архитектура → реализация → запуск → тесты → итерации → документация.
- **R-18** Работает в реальной среде Windows: создаёт проект, ставит зависимости, запускает,
  читает ошибки, правит.
- **R-19** Длинные сессии (часы) с чекпойнтами, восстановлением после сбоя, git-коммитами.
- **R-20** Режим «не спрашивай» настраивается по классам действий, а не «всё или ничего».

### Связь и контроль
- **R-21** Коннекторы: Telegram, Google Calendar/Gmail, Notion, Obsidian, Slack, Home Assistant,
  MCP-серверы любых типов.
- **R-22** Алерт в Telegram по каждому значимому действию + кнопки «Стоп», «Откатить»,
  «Разрешить всегда».
- **R-23** Полный журнал: что услышал, как понял, что вызвал, что изменилось, чем закончилось.
- **R-24** Откат: корзина, снапшоты файлов перед изменением, точка восстановления Windows для
  крупных операций.

### Продукт
- **R-25** Electron, Windows 10 (1809+) и 11, x64 (+ arm64 в перспективе).
- **R-26** Полностью бесплатно, без подписок; опциональные облачные ключи — только если сам
  вставил.
- **R-27** Красиво и понятно: «человеческий» интерфейс, а не дашборд для инженера.
- **R-28** Работает на слабом ПК (4–8 ГБ RAM, без дискретной GPU) в урезанном, но честном режиме.

## Ключевые принципы (не обсуждаются)

1. **Local-first, offline-capable.** Любая базовая функция работает без интернета. Сеть —
   это инструмент, а не зависимость.
2. **Least privilege.** Каждый инструмент объявляет нужные права. Нет прав — нет вызова.
3. **Confirm-by-risk.** Классы: `read` (молча), `write-local` (по настройке), `destructive`
   (всегда подтверждение, если не выдан явный allow), `money/identity/external` (всегда).
4. **Everything is a tool call.** Никакой компонент не делает побочных эффектов в обход
   реестра способностей → всё логируется, всё отменяемо, всё ограничиваемо.
5. **Observable by default.** Каждый шаг — событие в журнале с correlation id.
6. **Graceful on weak hardware.** Деградация по уровням, а не «не запустилось».
7. **User can always stop.** Голосом, горячей клавишей, кнопкой в трее, из Telegram.

## Уровни возможностей (Capability Tiers)

Профилировщик присваивает ПК уровень; от него зависит всё остальное.

| Tier | Железо (ориентир) | Что доступно |
| --- | --- | --- |
| **T0 «Минимум»** | 4–8 ГБ RAM, CPU-only, HDD | ASR small/tiny, TTS Piper, LLM 0.6–1.7B Q4, правила вместо LLM-планировщика, без VLM (UIA+OCR) |
| **T1 «Офисный»** | 8–16 ГБ RAM, iGPU | + LLM 3–4B, OCR нейро, embed локально, VLM квантованный на крайний случай |
| **T2 «Игровой/рабочий»** | 16–32 ГБ RAM, GPU 6–12 ГБ VRAM | + LLM 7–8B/14B, VLM 2–7B, стриминговый ASR, кодер-модель |
| **T3 «Станция»** | ≥32 ГБ RAM, GPU ≥16 ГБ VRAM или 24+ | + MoE 30B-A3B, VLM 7–9B, две-три модели одновременно, локальная fine-tune |

## Что считается «готово» (Definition of Done для v1)

Демо-сценарий, который должен проходить на T1-машине без интернета (кроме п.6):

1. «Хелпер, создай на рабочем столе папку Проект X» → папка создана, голосовой отчёт.
2. «Удали её» → **переспрашивает**, после «да» — в корзину, отчёт с кнопкой «Вернуть».
3. «Открой YouTube и найди видео про Minecraft» → браузер открыт, поиск выполнен.
4. «Перескажи это видео» → скачивание аудио, ASR, конспект с таймкодами.
5. «Сделай мне приложение для учёта расходов на Python» → план, 3–5 файлов, запуск, тест,
   git-коммит, отчёт, ссылка на папку.
6. «Поставь в календарь встречу в пятницу в 15:00» → подтверждение → создана, алерт в Telegram.
7. «Хелпер, стоп» в любой момент → всё останавливается за < 1 с, состояние сохранено.

## Анти-цели

- Не собирать данные пользователя, никакой телеметрии по умолчанию.
- Не требовать аккаунта, ключа, подписки для базовой работы.
- Не обещать «делает всё» — обещать «делает то, что умеет, и честно говорит, чего не умеет».
- Не запускать скачанные из сети скрипты без песочницы/подтверждения.
