# 27 — Карьера, безопасность, устройства: расширение без раздувания

Реестр: **724 действия / 45 доменов**. Профили: **16 приложений / 112 операций**.
Эта заметка фиксирует последний блок расширения — и, что важнее, его границы.

---

## 1. Работа и карьера (новый домен `career`, 14 действий)

Поиск работы — это десятки часов одинаковых компьютерных действий, и почти все они
безопасны, пока не доходит до «отправить».

| Этап | Действия | Риск |
| --- | --- | --- |
| Понять рынок | найти вакансии, сравнить по требованиям и деньгам, проверить репутацию компании | R |
| Упаковать себя | резюме под вакансию, сопроводительное, портфолио | W |
| Подготовиться | ответы к интервью, вопросы работодателю | W |
| Откликнуться | заполнить анкету и отправить отклик | **E** (подтверждение, данные профиля) |
| Вести процесс | трекер откликов, статусы из почты, сравнение офферов | R |
| Переезд | документы, виза, жильё, налоги — как чеклист | W |

Принципы:

1. **Резюме не выдумывает.** Каждое утверждение в резюме и письме должно опираться на факт
   из профиля пользователя; иначе — «не хватает данных», а не красивая фраза.
2. **Отклик — только с показом полного текста** и адресата. Массовые рассылки — `never`.
3. **Сравнение офферов — арифметика, не совет**: сумма, налоги, бонусы, акции, стоимость жизни,
   всё с формулами и источниками курсов.

## 2. Безопасность: добавляем только то, что снижает риск (6 действий)

| Действие | Метод | Риск |
| --- | --- | --- |
| Включить 2FA | TOTP: секрет в `secrets.enc`, показ QR | I |
| Проверить утечки паролей | k-anonymity запрос к HIBP: наружу уходит 5 символов SHA-1-хэша | R |
| Резервные коды 2FA | шифрованное хранилище + напоминание распечатать | W |
| Кто имеет доступ к аккаунту | список OAuth-приложений и активных сессий | R |
| Заблокировать подозрительную сессию | разлогин везде | D |
| Зашифровать папку/диск | BitLocker / VeraCrypt | D |

Жёсткие правила:

- **Пароли не читаем.** ZShelper не «смотрит» в менеджер паролей и не печатает их в логи;
  максимум — проверить, что пароль надёжен, по метрике, не показывая значение.
- **Шифрование — «разрушительное»**, потому что потеря ключа = потеря данных: обязательный
  тест восстановления на пустом файле до применения к папке.
- **Никаких «обходов»**: если сервис требует капчу — останавливаемся, а не решаем её.

## 3. Устройства и сеть (9 действий)

| Действие | Метод | Риск |
| --- | --- | --- |
| Подключить телефон, слить фото | ADB/MTP, инкрементально по датам | W |
| Скриншот экрана телефона | scrcpy / `adb exec-out screencap` | R |
| Установить APK | `adb install` (только свои сборки) | D |
| Кто в моей Wi-Fi | ARP-скан + имена по MAC | R |
| VPN | WireGuard/встроенный клиент | W |
| Проверить DNS-утечки | тест резолверов | R |
| Правило firewall | Windows Firewall API + проверка доступности после | D |
| Скорость соединения | локальный speedtest | R |
| Линтеры, уязвимости, Docker | ruff/pre-commit, pip-audit/OSV, docker build | W/R |

Смысл: это не «хакерские» функции, а гигиена. Пользователь, который не может проверить
утечки и увидеть чужие устройства в сети, живёт в неведении — приложение обязано показать.

## 4. Ввод: макросы как компромисс с хрупкостью GUI (2 действия)

Запись действий пользователя и воспроизведение — самый быстрый способ получить «руки»
там, где нет API. Ограничения, зафиксированные в реестре:

- запись **не сохраняет** значения паролей и содержимое буфера обмена;
- воспроизведение идёт **с проверками** (после каждого шага — ожидаемое состояние), иначе
  сценарий превращается в «слепой кликер»;
- макрос помечается «непроверенный», если приложение обновилось (см. `25-app-profiles.md`).

## 5. Почему мы не добавляем «всё подряд»

Собственность реестра — не количество строк, а **отношение строк к проверкам**:

| Метрика | Значение |
| --- | --- |
| Действий | 724 |
| Действий с известной проверкой результата | 724 (проверка выводится из домена, см. `docs/EVALS.md`) |
| Профилей (доведено до кнопок) | 16 |
| Операций в профилях | 112 |
| Дырок по семействам действий | **0** |

Отсюда правило следующей итерации: **новые домены только вместе с профилем или eval-планом**,
иначе получается энциклопедия, а не продукт.

## 6. Тонкие места, которые видно честно

- 26 доменов пока без профилей (полный список — [`docs/COVERAGE.md`](../../docs/COVERAGE.md)).
- T3-функции (демуксинг, VLM, генерация медиа) есть в реестре, но на слабом ПК будут
  «кнопкой с предупреждением», а не рабочим сценарием.
- Домены `legal-docs` и `personal-finance` требуют **дисклеймера в интерфейсе**, а не только
  в документации: пользователь не должен думать, что получил юридическую или налоговую консультацию.
