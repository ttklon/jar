# Roadmap — ZShelper

Статус: **M0 — исследование** (этот этап). Ниже — план по этапам с критериями выхода.
Оценки — в «человеко-днях» одного агента, не календарные обещания.

> Точка входа для человека или модели без контекста — [`AGENTS.md`](../AGENTS.md): состояние,
> карта артефактов, рецепты, инварианты. Роадмап — это план, AGENTS.md — как в нём жить.

## M0 · Исследование и фундамент ✅ (текущий)

- [x] Vault источников: ~740 репозиториев/пакетов, ~16 МБ текстов, `research/INDEX.md`
- [x] Инвентаризация MCP: ~1470 серверов, каталогизация по доменам (`research/discovery/`)
- [x] Конспекты по 16 направлениям (`research/notes/00…16`)
- [x] Требования разложены на R-01…R-28
- [ ] Проверить ключевые технические гипотезы на прототипах (см. M1)

**Выход:** можно начинать код, нет «слепых зон» в архитектуре.

## M1 · Скелет приложения и «руки» (2–3 недели)

- [ ] **Tauri 2 + React 19/TS strict** (решение — [`DECISION-STACK.md`](DECISION-STACK.md)), окно с Mica, трей, хоткеи, capability-манифест
- [ ] Rust-ядро: команды IPC, менеджер сайдкаров (llama.cpp/whisper.cpp), логирование
- [ ] Спайк до основной работы: release-сборка без портов, без DevTools, single-instance, офлайн (см. [`RUNTIME.md`](RUNTIME.md) §5)
- [ ] SQLite-схема (events/jobs/steps/audit/facts), миграции
- [ ] Нативный слой: скриншот, UIA-дамп, клик/ввод, проверка после действия (**прототип Rust**)
- [ ] Capability registry, сгенерированный из `data/actions.json` (792 действия) + первые 10 инструментов
- [ ] Загрузчик профилей `data/profiles/*.json` + движение по шагам с обязательной верификацией (`tools/profiles.py` уже валидирует данные)
- [ ] `tools/uia_probe.py`: авто-профиль из UIA-дампа (tier B) + визуальный агент как fallback (tier C)
- [ ] Policy engine (3 режима) + аудит + подтверждение в UI
- [ ] Профилировщик железа (статика + калибровка)

**Выход:** «создай папку», «удали в корзину», «открой приложение» — работают, всё логируется,
опасное переспрашивает.

## M1.5 · Сервер лицензий и защита сборки (2–3 дня)

- [ ] VPS: Caddy + API (Axum/Fastify) + Postgres, `POST /v1/activate|refresh|deactivate|entitlements`
- [ ] Ed25519-ключ подписи на сервере (файл 0400 / KMS), токен TTL 72 ч, привязка к устройству (TPM)
- [ ] Клиент: активация, кэш токена (DPAPI), офлайн-грейс 7 + 7 дней, экран «Лицензия»
- [ ] Вебхук оплаты (MoR: Paddle/Lemon Squeezy) → выпуск ключа → письмо
- [ ] Подпись кода: Azure Artifact Signing; MSIX-сборка в CI; проверка `signtool verify`
- [ ] Тесты деградации из [`LICENSING.md`](LICENSING.md) §8

**Выход:** подписка работает: оплата → ключ → активация на 2 устройствах → офлайн-режим →
корректная деградация при истечении и отзыве.

## M2 · Голос (2 недели)

- [ ] WASAPI-захват, Silero VAD, PTT-хоткей, индикатор
- [ ] whisper.cpp (turbo Q5) + словарь-промпт, двухпроходный ASR
- [ ] TTS: Kokoro/Piper, очередь по предложениям, barge-in
- [ ] Машина состояний аудио, «стоп» в audio-воркере

**Выход:** голосовой сценарий «услышал → сделал → сказал» с латентностью ≤ 1.5 с (p50).

## M3 · Мозги (3 недели)

- [ ] Менеджер моделей: манифест, скачивание, sha256, LRU, `llama-server`
- [ ] Router (1.7B, JSON-схема) + Planner (4B/8B) + verifier
- [ ] Retrieval инструментов (BM25 + embed), карточки инструментов
- [x] Формат скиллов + первые 10 рецептов: «сделай трек», «сдай курсовую», «приведи систему
      в порядок», «смонтируй и опубликуй ролик», «подведи итоги недели», «выставь счёт»,
      «бэкап 3-2-1», «исследуй и напиши отчёт», «разбери фотоархив», «откликнись на вакансию»
      (`data/skills/`, валидатор `tools/skills.py`)
- [ ] Скиллы на ежедневные операции оркестратора: папки, окна, браузер, заметки —
      те, что человек делает в два-три нажатия и ждёт от голоса
- [ ] Память: факты + эпизоды + гибридный поиск

**Выход:** 15 типовых голосовых задач выполняются без ручного вмешательства.

## M4.6 · Музыка и медиа-конвейер (1.5 недели)

- [ ] Пайплайн «трек под ключ»: референсы → бит (MIDI+шаблон) → текст → сведение → мастеринг
- [ ] REAPER-профиль (ReaScript) как основной «полный автомат»; FL Studio — шаблон + UIA
- [ ] `matchering` + `pedalboard` + `loudnorm`: измеримые критерии (LUFS, true peak, клиппинг)
- [ ] Три чекпойнта подтверждения: бит, текст, голос
- [ ] Опция клонирования **своего** голоса (T3, согласие, пометка AI-assisted vocal)

**Выход:** «сделай трек в стиле X на 2 минуты» → готовый WAV + стемы + текст + мастер.

## M4.5 · Документы и академическое письмо (2 недели)

- [ ] Пакет сдачи: DOCX + PDF + `sources/` + `Отчёт_о_проверке.md`

**Выход:** «напиши курсовую по теме X» → на выходе редактируемый Word с реальными источниками.

## M4.7 · Покрытие приложений Windows (фоновая линия, весь проект)

Не отдельный этап, а постоянный цикл, который идёт параллельно всем остальным.

- [x] Каталог 134 приложений с каналом, tier и приоритетом (`data/app_targets.psv`)
- [x] Генератор авто-профилей `tools/uia_probe.py` (dump → draft), классификация интерфейса
- [x] Профили P0: Диспетчер задач, Windows Terminal, Everything (Службы и Планировщик — через
      `sc.exe` / `schtasks`, в профиле диспетчера)
- [x] Профили P1: Параметры Windows, Просмотр событий, Docker, Панель управления, Firefox,
      WhatsApp, VirtualBox, HWiNFO — **готовы**; CrystalDiskInfo — покрыт через smartctl
- [x] Профили P2: DaVinci Resolve, Visual Studio, JetBrains (IDEA/PyCharm/Android Studio),
      WinSCP, FileZilla, DBeaver, tshark, robocopy/smartctl
- [x] Профили P2 остаток: Slack, LibreOffice, Acrobat, CapCut, Steam (углублён до 9 операций)
- [x] Профили-инструменты и классы: `kind: tool` (robocopy, tshark, soffice, beets, AHK) и
      `kind: system` (устройства, безопасность аккаунтов, календарь)
- [x] Политика `data/domain_profile_policy.json`: домен без профиля обязан быть классифицирован
      (аудит падает на неклассифицированном)
- [x] Медиа-конвейер как инструмент: `ffmpeg.json` (субтитры, LUFS, SSIM, склейка, изоляция вокала)
- [x] Мелкие домены дотянуты до глубины ≥0.5: `distribution` (релизный конвейер),
      `monitoring-triage` (алерты и разбор инцидентов), `engineering-3d` (FreeCAD + слайсеры),
      `accessibility`, `display-sound`, `system-power`
- [x] Домены с самой низкой глубиной выровнены: `databases` (SQLite CLI + PostgreSQL CLI:
      миграции в транзакции, бэкап `VACUUM INTO` / `pg_dump -Fc`, восстановление с проверкой,
      права и роли, медленные запросы) и `business-finance` (счета и акты, реестр за период,
      сверка оплаты, дубли, ИНН/ОГРН по контрольной сумме, прогноз кассы) — 0.40 → 1.0+
- [ ] Tier C: список приложений-канвасов + политика «визуальный агент с проверкой по скриншоту»
- [ ] Дрейф: пере-проверка якорей по `verified_at` старше 90 дней, отчёт в CI
- [x] Домены без профиля: очереди нет — `smart-home` закрыт профилем хаба
      (`home-assistant.json`, `kind: system`), остальные 9 — решения
      (health-daily, travel, home-daily, languages, career, ai-ml, legal-docs, licensing,
      superhuman): каждый закрывается скилл-рецептом, коннектором, бенчмарком или API, а не
      профилем приложения. См. `research/notes/32-artifact-types.md`

**Состояние:** 81 профиль / 522 операции, tier A — 70 из 136 приложений каталога.
Приложений P0 и P1 без профиля — **нет**. Самая низкая глубина домена — 0.40
(`hardware-diag`: 8 операций на 20 действий).

**Критерий выхода линии:** ≥60 профилей tier A + ≥30 приложений, прошедших авто-профиль с
подтверждением вручную; ни одного приложения из P0 без профиля.

## Риски расписания

| Риск | Влияние | Что делаем |
| --- | --- | --- |
| Нативный слой Windows дольше, чем кажется | сдвиг M1 | прототип на 2 дня первым делом; fallback на nut-js |
| Слабый tool-calling у мелких моделей | качество | retrieval инструментов, JSON-схемы, один инструмент на шаг |
| SmartScreen/антивирус | установка | portable-сборка, документация, подпись позже |
| Компьютер-юз агенты нестабильны (реальность 2026) | ожидания | узкие скиллы с проверками вместо «универсального агента» |
