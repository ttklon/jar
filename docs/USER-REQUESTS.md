> Журнал содержит пользовательские запросы, не ответы ассистента и не сообщения платформы. Имеющиеся в истории сокращённые пересказы не выдаются за дословные цитаты. Полный исходный архив доступен пользователю в интерфейсе переписки; в текущий рабочий контекст ранее поступила лишь сокращённая история, поэтому восстановить точные старые формулировки из неё нельзя.

## 2026-11-08 — консолидированные требования и предоставленный пользователем архив

Пользователь предоставил большой свод собственных прежних запросов о ZShelper. Его содержимое структурировано без претензии на дословную стенограмму в [`USER-REQUIREMENTS.md`](USER-REQUIREMENTS.md). Ключевые постоянные пожелания: практическая разработка Windows desktop-голосового агента; разговор как основной сценарий, в том числе со свёрнутым окном; понятная установка AI-компонентов на первом запуске; голосовые задачи и длительное выполнение с командой остановки; адаптация моделей и нагрузки к ПК; осторожное подтверждение рискованных действий; безопасное согласие на расширения; журналирование и опциональные уведомления; тестируемые обновления и честные заявления о готовности.

Пользователь отдельно просил сделать файл обязательных инструкций для агента, сохранять пользовательские запросы/промпты для продолжения контекста, внести изменения, закоммитить и запушить. Для будущих запросов действует порядок из `AGENT.md`; чувствительные данные не копировать в журнал. Дословно восстановить более ранние сообщения, не присутствующие в контексте этой сессии, невозможно.
